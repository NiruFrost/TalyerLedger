## Description

An upload can succeed before its metadata insert fails because Storage and
PostgreSQL are not one transaction. Define a safe reconciliation mechanism.

## Acceptance criteria

- [ ] Identify Storage objects without valid active metadata.
- [ ] Exclude in-flight uploads and retain an appropriate safety window.
- [ ] Delete or quarantine confirmed orphans with an auditable log.
- [ ] Add monitoring and tests for failed metadata insertion.
- [ ] Update the threat model and operational documentation.
